📐 End-to-End System Architecture & Data Pipeline

Production Design

1. Multi-Source Ingestion & NLP

Ingests unstructured text from Financial News (Reuters/Bloomberg/GDELT) and Social Media (Twitter/X FinTwit, StockTwits). Extracts entities & tickers, assigns Loughran-McDonald bounded sentiment [-1.0, 1.0], classifies events across 7 taxonomic classes, and computes market impact score (1-10).

2. Module A: Tactical Rebalancing

Subscribes to real-time stock sentiment signals. Dynamically adjusts S&P 100 constituent weights via alpha tilt: wᵢ = wᵢ,base × (1 + α × Sᵢ) / Σ. Applies turnover controls, tracking error safeguards, and generates dynamic active alpha outperformance.

3. Module B: Portfolio Stress Testing

Automated threshold trigger upon high-severity events (Impact ≥ 7.0). Simulates shocks on $525M wholesale banking portfolio (loans, bonds, swaps). Computes post-stress valuation, Merton ECL, Modified Duration bond drops, derivative MTM, and Basel III CET1 capital adequacy.
